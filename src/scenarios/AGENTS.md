# scenarios

## Purpose

Published fixture series for `vue-relative-rotation-chart/scenarios` (demo + copy-as-code).

## Belongs here

- Precomputed `RrgRenderSeries[]` fixtures and trail helpers
- Public barrel (`index.ts`) + `scenarioFixtures` map

## Does not belong here

- Demo UI catalog (display names, intents) — stays in `demo/scenarios.ts`
- Seeded generator / BYO JSON helpers — stay in `demo/`
- Chart rendering or RRG calculation

## Depends on

- `src/types/rrg`

## Used by

- Package consumers via `vue-relative-rotation-chart/scenarios`
- Demo playground catalog
