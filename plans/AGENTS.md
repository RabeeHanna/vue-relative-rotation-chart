# plans

## Purpose

Unit-of-work specifications and recorded design decisions.

## Belongs here

- `00-overview.md` and `PRE-C1-*` / `C*` plan files
- Decision records appended when a pre-start unit completes

## Does not belong here

- Production source code
- Long essays duplicated from README

## Depends on

- Nothing runtime

## Used by

- Humans and agents implementing features in order
- Cross-links between dependent units (e.g. C6 → PRE-C1-A)
